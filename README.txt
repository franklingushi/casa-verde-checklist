CASA VERDE · PWA
==================

Esta carpeta contiene la versión instalable como aplicación web (PWA).

Archivos:
- index.html
- manifest.json
- service-worker.js
- icons/icon.svg

IMPORTANTE:
Para que Android permita "Instalar aplicación", debe publicarse en una dirección HTTPS.
Una opción sencilla es GitHub Pages.

Una vez publicada:
1. Abrir la dirección en Chrome del POCO.
2. Tocar ⋮.
3. Elegir "Instalar aplicación" o "Añadir a pantalla de inicio".
4. Confirmar.
